
# 5-sonli Politexnika Texnikumi - Rasmiy Veb-Sayti

Farg'ona viloyati 5-sonli politexnika texnikumi rasmiy veb-sayti frontend qismi.

## Ishga tushirish

1. Bog'liqliklarni o'rnatish:
```bash
npm install
```

2. Loyihani ishlab chiquvchi rejimida ishga tushirish:
```bash
npm run dev
```

3. Production uchun yig'ish:
```bash
npm run build
```
